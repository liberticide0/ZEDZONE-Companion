# 개발 상태 · 2026-11-09

기준은 개발계획서 v1.2와 기존 v0.2.0이다. 계획 전체는 미완료다. 로컬 브랜치 `companion/steam-local-catalog`의 기존 작업과 조사·QA 기록을 이어간다.

- 재검증 완료: Steam 빌드 26528677, 아이템 자산 717개, 제작법 보유 자산 312개, 정적 제작법 375건.
- 기존 검증 재사용: Steam 현지화 자동 읽기, Windows 11 포터블 실행, 게임 메뉴와 플레이에서 단축키·Esc 복귀.
- 구현: `probe-recipes.py --snapshot`이 사용자 폴더에 빌드별 자료를 원자적으로 생성한다. 앱은 Steam 빌드 일치와 ID·명칭을 확인한 뒤 아이템 상세·제작법 분류에 연결한다. 작업대별 선택, 목표 수량, 도구 분리, 부분 계산과 계산 보류를 지원한다.
- 범위: 자산 717개, 정적 제작법 375건, 연결 연구가 있는 제작법 보유 자산 38개. 현지화에서 구분 가능한 활성 스킬 설명 206개, 지역 4개와 보스 자산 이름 5개를 변환했다. 내장 설명과 영어명이 같은 공략은 앱에서 중복을 숨긴다.
- 검증: Release 빌드와 자동 검증 35건. 최종 ZIP에서 375건 로딩, 12 게이지 양쪽 작업대 및 연구 조건, 스킬·지역·보스 검색, 실제 플레이의 단축키·검색·Esc 게임 복귀를 확인했다. [QA 기록](qa.md)
- 데이터 차단 범위: 산출물 불일치 34건 중 24건은 결과 ID가 0이고 10건은 다른 기존 아이템 ID다. 개발사 문서의 MOD 필드 정의만으로 기본 게임에서 실행 시 어떻게 해석되는지 확정할 수 없다. 전부 표시하되 수량 계산을 보류한다. 음수 재료는 15건이며 인게임으로 대조한 12 게이지의 멀티툴을 제외하면 소모 계산에 넣지 않는다.
- 다음 실행: 런타임 등록 규칙에 대한 공식 자료를 확인하고, 필요한 경우 0과 비영 산출물 및 음수 소수 수량 각각의 대표 사례만 읽기 전용으로 대조한다. 증거가 확보되면 계산 보류를 축소한다. 이후 Workshop 데이터 지원은 기본 게임과 별도 출처로 설계한다.
- 환경별 완료 조건: Windows 10, 인터넷이 끊긴 세션, 창 모드별 한글 IME·DPI는 별도 환경이 필요하다. 현재 PC에는 Wi-Fi가 연결돼 있고 네트워크 차단용 VM 도구가 확인되지 않았다. 설치 파일 기반 검색·계산은 독립적으로 완료했다. 전체 Phase 1–4는 부분 완료다.
- 새 PC의 최초 변환은 Python과 두 파서 패키지에 의존한다. ZIP에는 자체 변환 스크립트가 있다. 변환기까지 설치 없이 제공하려면 파서의 전이 의존성과 네이티브 라이브러리 고지를 확인하고 깨끗한 Windows에서 별도로 검증한다.
- 로컬 검증본은 `artifacts/ZEDZONE-Companion-0.3.0-win-x64.zip`이다. SHA-256은 `a4bcc7efe41a3dd348a114ae2d575b59f4312222e684935d85fdedf9dea98722`이다. 원격 게시 없음.
