UI 확인에는 키보드 입력과 접근성 트리를 사용했다. 시각 확인은 포인터와 클릭 표시가 대상 영역을 가리지 않는 상태에서 했다. 게임은 기존 Steam 설치를 정상 실행했고 플레이 세이브는 열지 않았다. 앱의 검색과 자료 읽기는 로컬 파일 및 메모리에서 처리된다. 네트워크를 끊은 상태의 별도 실측은 하지 않았다.

## 남은 검증

- Windows 10 x64, 독점 전체 화면, 복수 모니터·배율 조합, 실제 플레이 및 협동 중 입력 충돌
- 전역 단축키 두 개 모두 선점된 환경과 보조 단축키 경로
- 공식 MOD 에디터에서의 직접 내보내기 및 전체 바닐라 제작법·해금 조건 대조

실제 플레이에서 재현할 때는 게임을 창 모드 또는 테두리 없는 창 모드로 실행한 뒤 Ctrl+Shift+Space로 검색창을 열고 **돌망치**를 입력한다. Esc를 눌러 검색창이 숨겨지고 게임 입력이 돌아오는지 확인한다. 기본 단축키가 충돌하면 화면 하단의 단축키를 사용한다.

## v0.1.1 · 12 게이지 검색

사용자 제보의 게임 내 작업대 제작 목록에서 항목을 확인했다. 공식 아이템 ID는 100이다. 파일을 불러오지 않은 상태에서 전체 검색에 아이템과 제작법이 모두 표시되는지, 한국어·영어·중국어·ID 검색이 각 분류에서 작동하는지 자동 검증했다. 작업대 세부 종류와 제작 수치는 미검증이다. [개발사 아이템 ID 표](https://raw.githubusercontent.com/IndieDev-LevenLiu/zedzone/c84e688c5df9c9c6cf93ce851a72ebc716ae4d20/mod-docs/docs/en/12_Item_ID_Reference.md)

자동 검증에는 보조 Steam 라이브러리, 읽을 수 없는 CSV의 내장 검색 복귀, 수동 CSV 우선, 동일 ID의 이름 충돌, 매니페스트의 상위 경로 거부가 포함된다. 포터블 UI의 `84mm 고폭탄` 검색에서 현지화 아이템과 별도 제작법이 함께 표시되는 것도 확인했다. 검증 전후 실제 현지화 파일 SHA-256이 같았다. 배포용 ZIP에는 게임 원본, 공식 ID 표, 추출 데이터가 없다.

사용자가 미리 열어 둔 월드의 제작 목록 위에서 v0.2.0 오버레이를 호출했다. `12 게이지`를 한글 문자열로 입력해 아이템·제작법·탄피 결과를 확인했다. Esc로 오버레이를 숨기자 게임이 전면에 왔고, 게임에 Esc를 한 번 더 입력하자 제작 목록이 닫혔다. 저장과 제작 입력은 하지 않았다. 이 세션에는 외형용 Workshop 모드가 활성화돼 있었다. 모드 아이템 검색은 이번 검증 범위에서 제외했다. `12 게이지`의 작업대 종류, 재료·수량은 이번 화면에서 확인하지 않았다.

네트워크를 분리한 실측은 원격 작업 연결을 유지한 상태에서 수행하지 않았다. 재현할 때는 인터넷이 끊긴 로컬 Windows 세션에서 ZIP을 풀고 실행한 뒤 `금속 화살`을 검색한다.
