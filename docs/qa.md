# 검증 결과 · 2026-11-09

검증 환경은 Windows 11 x64, Steam ZED ZONE **1.0.12**(빌드 **26528677**)다.

| 항목 | 결과 |
|---|---|
| Release 빌드 | `dotnet build src/Companion -c Release` 완료, 경고 0건, 오류 0건 |
| 검색·자료 검증 | 자동 검증 14건 통과. 한국어, 영어, 중국어, 전각 숫자 ID, 분류, 결과 없음, 인용부호와 여러 줄 CSV, 다른 버전의 이름 충돌, 잘못된 파일 입력 시 기존 자료 유지 등을 확인했다. |

| 실제 게임 위 표시 | ZIP에서 푼 프로그램을 실행했다. 게임 메뉴에서 Ctrl+Shift+Space를 누르자 Companion이 게임 창 위에 나타났고 검색 입력에 포커스가 잡혔다. |
| Esc와 복귀 | Esc 이후 Companion 창이 숨겨지고 별도 전환 입력 없이 ZED ZONE 창이 전면으로 돌아왔으며 포커스를 받았다. |
| 제작 계산 | 방사능 폭탄 목표 3개를 입력하자 즉시 2회 제작, 생산 4개, 연료봉 2개가 표시됐다. 수량이 미검증인 재료는 계산에서 분리했다. |
| 자료 선택 | 자료 선택 대화상자 열기·취소를 확인했다. 실제 원본 파일의 로딩은 파서에서 검증했다. 대화상자에서 파일을 선택해 검색하는 전체 흐름은 미검증이다. |
| 패키지 | Windows x64 ZIP을 새 폴더에 풀어 실행했다. ZIP의 SHA-256과 실행 파일, 문서, 프로젝트·런타임 라이선스 구성도 확인했다. |

UI 확인에는 키보드 입력과 접근성 트리를 사용했다. 시각 확인은 포인터와 클릭 표시가 대상 영역을 가리지 않는 상태에서 했다. 게임은 기존 Steam 설치를 정상 실행했고 플레이 세이브는 열지 않았다. 앱의 검색과 자료 읽기는 로컬 파일 및 메모리에서 처리된다. 네트워크를 끊은 상태의 별도 실측은 하지 않았다.

## 남은 검증

- Windows 10 x64, 독점 전체 화면, 복수 모니터·배율 조합, 실제 플레이 및 협동 중 입력 충돌
- 전역 단축키 두 개 모두 선점된 환경과 보조 단축키 경로
- 공식 MOD 에디터에서의 직접 내보내기 및 전체 바닐라 제작법·해금 조건 대조

실제 플레이에서 재현할 때는 게임을 창 모드 또는 테두리 없는 창 모드로 실행한 뒤 Ctrl+Shift+Space로 검색창을 열고 **돌망치**를 입력한다. Esc를 눌러 검색창이 숨겨지고 게임 입력이 돌아오는지 확인한다. 기본 단축키가 충돌하면 화면 하단의 단축키를 사용한다.

## v0.1.1 · 12 게이지 검색

사용자 제보의 게임 내 작업대 제작 목록에서 항목을 확인했다. 공식 아이템 ID는 100이다. 파일을 불러오지 않은 상태에서 전체 검색에 아이템과 제작법이 모두 표시되는지, 한국어·영어·중국어·ID 검색이 각 분류에서 작동하는지 자동 검증했다. 작업대 세부 종류와 제작 수치는 미검증이다. 자동 검증에는 보조 Steam 라이브러리, 읽을 수 없는 CSV의 내장 검색 복귀, 수동 CSV 우선, 동일 ID의 이름 충돌, 매니페스트의 상위 경로 거부가 포함된다. 포터블 UI의 `84mm 고폭탄` 검색에서 현지화 아이템과 별도 제작법이 함께 표시되는 것도 확인했다. 검증 전후 실제 현지화 파일 SHA-256이 같았다. 배포용 ZIP에는 게임 원본, 공식 ID 표, 추출 데이터가 없다.

네트워크를 분리한 실측은 원격 작업 연결을 유지한 상태에서 수행하지 않았다. 재현할 때는 인터넷이 끊긴 로컬 Windows 세션에서 ZIP을 풀고 실행한 뒤 `금속 화살`을 검색한다. 실제 플레이 실측은 테스트 가능한 월드를 사용자가 창 모드 또는 테두리 없는 창 모드로 열어 둔 상태에서 수행한다. 호출 후 한글 키 입력으로 검색하고 Esc로 숨긴 뒤, 제작 화면처럼 세이브를 바꾸지 않는 입력을 게임에서 확인한다.
