## 남은 검증

실제 플레이에서 재현할 때는 게임을 창 모드 또는 테두리 없는 창 모드로 실행한 뒤 Ctrl+Shift+Space로 검색창을 열고 **돌망치**를 입력한다. Esc를 눌러 검색창이 숨겨지고 게임 입력이 돌아오는지 확인한다. 기본 단축키가 충돌하면 화면 하단의 단축키를 사용한다.

자동 검증에는 보조 Steam 라이브러리, 읽을 수 없는 CSV의 내장 검색 복귀, 수동 CSV 우선, 동일 ID의 이름 충돌, 매니페스트의 상위 경로 거부가 포함된다. 포터블 UI의 `84mm 고폭탄` 검색에서 현지화 아이템과 별도 제작법이 함께 표시되는 것도 확인했다. 검증 전후 실제 현지화 파일 SHA-256이 같았다. 배포용 ZIP에는 게임 원본, 공식 ID 표, 추출 데이터가 없다.

사용자가 미리 열어 둔 월드의 제작 목록 위에서 v0.2.0 오버레이를 호출했다. `12 게이지`를 한글 문자열로 입력해 아이템·제작법·탄피 결과를 확인했다. Esc로 오버레이를 숨기자 게임이 전면에 왔고, 게임에 Esc를 한 번 더 입력하자 제작 목록이 닫혔다. 저장과 제작 입력은 하지 않았다. 이 세션에는 외형용 Workshop 모드가 활성화돼 있었다. 모드 아이템 검색은 이번 검증 범위에서 제외했다. `12 게이지`의 작업대 종류, 재료·수량은 이번 화면에서 확인하지 않았다.

네트워크를 분리한 실측은 원격 작업 연결을 유지한 상태에서 수행하지 않았다. 재현할 때는 인터넷이 끊긴 로컬 Windows 세션에서 ZIP을 풀고 실행한 뒤 `금속 화살`을 검색한다.

## v0.4.0 · 계획 v1.3 추가 기능

- Windows 11에서 최종 ZIP을 새 폴더에 풀어 실행했다. Release 빌드와 자동 검증 44건을 통과했다. 실행 파일 버전은 `0.4.0+bb0c07f`이다.
- Steam 빌드 26528677의 제작법 375건을 읽었고, 12 게이지와 12 게이지 탄피가 각각 ID당 한 결과로 표시됐다. 아이템 설명과 작업대별 제작법은 같은 상세 영역에서 열린다.
- 손 제작을 선택해 12 게이지 4발을 등록했다. 멀티툴 1개를 별도 도구로 표시하고 손 제작 2회·6발과 탄피·화약의 하위 제작 단계를 계산했다. 탄피 5개를 목표에 추가하니 공통 필요량 17개에 대해 탄약 압착기 3회·18개를 계획했다. 숯 제작의 불명확한 데이터는 부분 계산으로 표시했다. 두 목표와 합산 결과를 앱 재실행 뒤 복원했고, 수량 수정과 한 항목씩 제거도 확인했다.
- 최종 ZIP에서 수제 산탄총 4정을 목표로 검증했다. 직접 확보 재료로 나무 16개와 철광석 88개가 표시됐으며, 용광로·간이 작업대·간이 선반·작업대 순서에 따라 필요한 중간 단계가 출력됐다. 이 값은 설치 자산 기반 계획이며 인게임 제작을 실행해 소비량을 대조한 값은 아니다.
- 기본 제목표시줄 제거, 반투명 표시, 상단 드래그 이동과 작은 레이아웃 전환을 확인했다. 실행 중인 게임의 일시정지 화면 위에서 전역 호출, 한글 문자열 검색, Esc 및 닫기 버튼 후 게임 전면 복귀를 확인했다. 이번에 실제 제작이나 저장을 하지 않았다.
- 창 모드별, 물리 키보드 한글 IME 조합, 다중 모니터·DPI 조합, Windows 10, 네트워크 분리 상태는 미검증이다. 새 PC의 제작법 최초 준비에는 Python이 필요하다. 오디오 의존성 가져오기를 차단해도 같은 설치에서 생성한 로컬 변환 파일의 SHA-256은 같았다.

패키지는 `ZEDZONE-Companion-0.4.0-win-x64.zip`이며 SHA-256은 `334e72b8642b85541e93a23ef706f1ff366975fbbed43184be73f28803284edc`이다. ZIP에서 앱·자체 변환 스크립트·안내·라이선스만 확인했다. 원본, 변환 데이터, 찜목록은 포함하지 않았다.

- `CNC 부품`을 검색해 아이템 상세의 작은 출처 주석, 간이 선반 제작법의 작업대·회당 생산·회당 재료 정렬과 철판 1개를 확인했다. 목록에 이름과 오른쪽 분류 배지가 각각 표시됐다.
- 작은 창으로 전환하면서 검색 목록, 자료 버튼 두 개와 하단 상태가 표시되는 것을 확인했다. F1과 하단 버튼으로 단축키 및 자료 안내를 열었다.
- 게임 중 포커스 복귀와 다른 DPI·Windows 버전은 이번 변경에서 다시 측정하지 않았다.

## v0.4.3 · 찜목록 합산 제작 계획

- Release 빌드 경고·오류 0건, 자동 검증 44건을 통과했다.
- 기존 앱과 별도로 Windows 11에서 동일 화면을 검증용 목표 12 게이지 4발과 CNC 부품 2개로 열었다. 정렬된 합산 재료, 멀티툴 구분, 번호가 매겨진 제작 단계와 작업대·횟수·산출량, 부분 계산 안내를 확인했다.
- 포터블 ZIP 48개 항목 및 SHA-256 `848ccc2f7274463b66aab30b1343fe08afb6e3c54cca18dd90106c655c3d20b1`을 확인했다. 화면 검증은 별도 실행 창에서 수행했다.

## v0.4.4 · 재료 체크리스트와 건설 검색

- 합성 찜목록으로 기존 저장 파일 호환, 체크 저장·복원, 필요 수량·빌드가 다를 때의 체크 분리를 검증했다. Windows 목록 컨트롤에서 같은 수량의 체크와 취소선이 복원되고 수량이 달라지면 일반 글자로 표시되는 것을 확인했다. 직접 클릭과 인게임 화면은 이번 검증 범위에 포함하지 않았다.
- Steam 빌드 26554206의 원본을 읽기 전용으로 변환해 기존 아이템 자산 717개·제작법 375건과 배치물 65개를 확인했다. 건설 검색은 아이템 ID와 독립적으로 검증했으며, 건설 항목은 제작법 분류에도 표시된다.
- 배치물 65개는 `properties/terrainobjects` 357개 중 재료 행이 있는 자산이다. 배치물의 원본 결과 ID는 모두 해당 배치물 ID와 같았고, 재료 ID는 모두 아이템 자산에 대응했다. 옥수수 자산의 수량 0 행은 미확인으로 표시했다. 설치 파일의 영문 이름과 현지화 표가 일치한 12개는 한국어 이름을 표시한다. 게임 진행에 따른 배치 메뉴 노출 여부는 미검증이다.
- 벽·바닥·지붕의 복셀 건축은 배치물 레시피와 별도로 취급한다. 설치 파일에서 복셀 재료 관련 타입 이름을 확인했으나 비용 테이블과 연결하지 못했다.

## v0.4.5 · Steam 변환 자료 다시 열기

- Steam 빌드 26554206의 변환 파일은 생성됐지만, 거대 도마뱀 비늘가죽 사냥복의 변형 6건이 자산 목록에 없는 산출물 ID 10701~10703을 참조해 v0.4.4에서 전체 자료를 거부했다.
- 수정 후 앱의 설치 자료 로더로 기존 로컬 변환 파일을 다시 읽어 제작법 375건과 건설 항목 65개를 확인했다. 해당 변형 6건은 검색·상세에 남고 수량 계산은 보류된다. 미등록 산출물 허용과 잘못된 재료 참조 거부를 스모크 테스트에서 검증했다.

## v0.4.6 · 앱 내 업데이트

- Release 빌드 경고·오류 0건. 업데이트 통합 검증을 포함해 66건을 통과했다.
- Windows 11에서 최종 포터블 v0.4.6과 테스트 전용 v0.4.7을 사용했다. 격리된 HTTP 응답으로 정식 릴리스 조회, 파일 다운로드와 SHA-256 검증을 수행했다. 실제 업데이트 프로세스가 구버전 종료를 기다려 전체 패키지를 교체한 뒤 같은 경로에서 새 버전 창을 열었다.
- 재료 체크가 포함되는 찜목록 파일과 두 변환 자료의 해시, 설치 폴더의 관련 없는 파일이 유지됐다. 업데이트 중 바뀐 README의 복구, 잠긴 파일로 인해 교체가 실패했을 때 복구, 태그와 실행 파일 버전 불일치 거부를 확인했다.
- 사전 릴리스·초안·동일 버전 제외, 정식 릴리스 없음, 연결 실패, 해시 불일치, 외부 도메인으로 이동, 위험 ZIP 경로, 쓰기 권한 제한 및 Steam 폴더 거부를 확인했다.
- 실제 공개 GitHub 정식 릴리스 API는 404를 반환했다. 검증용 버전 안내의 두 버튼은 접근성 정보로 확인했으며 Windows가 잠겨 화면 배치와 실제 공개 자산의 앱 내 설치는 미검증이다.
- ZIP 48개 항목을 확인했다. 게임 원본·사용자 자료·변환 결과·파서 다운로드 파일은 포함하지 않았다.
